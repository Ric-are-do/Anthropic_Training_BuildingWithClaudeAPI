# RAG in This Project

## Chunking Methods

All chunking functions live in:
`utilities/Chunking/chunking.ts`

| Method | Overview |
|---|---|
| `chunkByChar(text, chunkSize, chunkOverlap)` | Size-based chunking — splits a string every `chunkSize` characters. `chunkOverlap` controls how many characters are shared between consecutive chunks. |
| `chunkBySection(documentText)` | Structure-based chunking — splits a markdown document on `## ` headings. Each section becomes its own chunk. |
| `chunkBySentences(text, sentencesPerChunk, overlap)` | Sentence-based chunking — splits text into individual sentences then groups them. `overlap` controls how many sentences are shared between consecutive chunks. |

---

## Test Document

`Rag_Documents/report.md` is the document used to test chunking. It is a fictional Annual Interdisciplinary Research Review containing 10 sections across different departments. It was chosen because it has clear `##` section headings, long paragraphs, and varied content — making it a good test case for all three chunking strategies.

---

## Testing Entry Point

`rag.ts` (project root) is the sandbox file for all RAG experimentation. It reads `report.md` into a string and passes it through whichever chunking method is currently active. The other methods are commented out so you can switch between them easily.

**Run it with:**
```
npm run rag
```
